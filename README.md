プライバシーポリシー

本プライバシーポリシーは、本Chrome拡張機能（以下、「本拡張機能」）におけるユーザー情報の取り扱いについて説明するものです。

取得する情報について

本拡張機能は、以下の情報を取得する場合があります。

・ユーザーが入力したテキスト
・拡張機能の設定情報
・問い合わせ内容などユーザーが入力したデータ

これらの情報は、本拡張機能の機能を提供する目的のみに使用されます。

情報の利用目的

取得した情報は、以下の目的で利用します。

・AIによる文章生成機能の提供
・ユーザーからの入力内容に対する返信文の生成
・拡張機能の動作および機能提供

外部サービスへの送信について

本拡張機能では、AIによる文章生成機能を提供するため、ユーザーが入力したテキストを以下の外部サービスに送信する場合があります。

OpenAI API

送信される情報は、文章生成の処理のためにのみ使用されます。

OpenAIのプライバシーポリシーについては、以下をご確認ください。
https://openai.com/privacy

個人情報の保存について

本拡張機能は、ユーザーが入力した内容を開発者のサーバーに保存することはありません。

第三者への提供

本拡張機能は、ユーザーの情報を第三者に販売・提供することはありません。

ただし、サービス提供のために必要な範囲で外部API（OpenAI等）へ情報が送信される場合があります。

セキュリティ

本拡張機能は、ユーザー情報の保護に配慮して設計されています。

ポリシーの変更

本プライバシーポリシーは、必要に応じて変更される場合があります。

お問い合わせ

本ポリシーに関するお問い合わせは、開発者までご連絡ください。
